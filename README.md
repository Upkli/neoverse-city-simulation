# NeoVerse – AI City Survival System

A console-based C++ city simulation project developed to demonstrate object-oriented programming, modular software design, file handling and system management.

## Overview

NeoVerse is a console-based city simulation built using C++. It consists of multiple interconnected systems designed to manage different aspects of a simulated city environment.

## Key Components

- **City Component:** Core city management functionality.
- **Emergency Event System:** Handles emergency-related events.
- **Engineer System:** Manages engineer-related functionality.
- **Health System:** Represents city health management.
- **Power System:** Handles power-related functionality.
- **Security System:** Represents city security management.
- **Transport System:** Handles transportation-related functionality.
- **Event System:** Supports event management.

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Standard Template Library (STL)
- File Handling
- Console-Based Application Development

## Project Structure

- `.cpp` files – implementation of the different systems.
- `.h` files – class declarations and interfaces.
- `main.cpp` – application entry point.

## Running the Project

The project was developed using Code::Blocks.

1. Open the project in Code::Blocks.
2. Build the project.
3. Run the application.

## Learning Outcomes

This project demonstrates practical application of C++ programming concepts, including modular development, classes, object-oriented design and file handling.
